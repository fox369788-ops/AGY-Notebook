### Slide 10：PAPA 理論四大核心議題
* **【頁碼與標題】**：Slide 10｜資訊倫理四大支柱：梅森教授的 PAPA 理論
* **【視覺與手繪設計】**：
  - 黑板上繪製 2×2 的四宮格粉筆筆記矩陣。
  - 四個格子分別用粉筆大字標出：【P】、【A】、【P】、【A】。
  - 每個英文字母旁搭配手繪符號：鎖頭（隱私）、放大鏡（準確）、版權徽章（所有權）、平等橋樑（可及性）。
* **【核心文字】**：
  | 字母 | 核心議題 | 核心精神與生活定義 |
  | :---: | :--- | :--- |
  | **P** | **資訊隱私權**<br>*(Privacy)* | 屬於法律「人格權」，個人有權決定資料是否被他人收集或利用。未經同意絕不碰！ |
  | **A** | **資訊準確性**<br>*(Accuracy)* | 提供者有義務確保內容真實；因錯誤資訊受害者，提供者須負賠償責任！ |
  | **P** | **資訊所有權**<br>*(Property)* | 尊重數位創作與智財產權，不盜拷、不破解、付費正版授權。 |
  | **A** | **資訊可及性**<br>*(Accessibility)* | 人人都享有公平獲取資訊的權利，積極弭平城鄉數位落差（資訊就是力量）。 |
* **【講者口語引導】**：
  - 「請大家把手借給我，一起記住這四個英文字母——P-A-P-A！第一個 P 是 Privacy 隱私權，別人的手機不要看；A 是 Accuracy 準確性，寫文章不要胡謅；第二個 P 是 Property 所有權，用盜版就是小偷；最後一個 A 是 Accessibility 可及性，偏鄉孩子也要有平板上網，縮短數位落差！」
