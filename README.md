# AGY-Notebook：教科書轉 AI 黑板微影音全自動生產線

> 專為國高中資訊科技教師打造的「**教科書轉 AI 課堂微影音**」標準化自動生產系統。  
> 深度整合 **Google Antigravity 4 大工作技能（Skills）** 與 **Google NotebookLM Video Overview**，將傳統紙本教材一鍵轉化為節奏緊湊（約 3.5 分鐘）、教室手繪黑板風格（Chalkboard Style）的高質感教學說明影片！

---

## 🎯 專案核心特色

1. **4 大專屬技能模組化**：包含 PDF 小節自動拆解、口語化重點提煉、3.5 分鐘黑板風大綱規劃、NotebookLM 自動化生成。
2. **時長與字數極限鎖定**：每大節拆為 3 支微影音，每段嚴格 4 頁黑板風、口播約 300~320 字，單支精控 3.5 分鐘，全小節總播放時長剛好 10~12 分鐘，完美適配課堂 1/4 節奏！
3. **無損 3 秒靜止收心片頭**：提供一鍵拖曳批次工具（FFmpeg），1 秒解決 NotebookLM 原生無法輸出靜音開頭的痛點，打造全班聚焦黑板、安靜沉澱的正式成片。
4. **單一目錄集中管理**：小節課文、重點摘要、分段大綱與後製工具全部集中於課本整章 PDF 同一資料夾，乾淨不混亂。

## 🛠️ 4 大專屬技能（Antigravity Skills）

| 技能名稱 | 核心任務 | 輸入 ➔ 產出 |
| :--- | :--- | :--- |
| **`textbook-pdf-splitter`** | 依目錄精準將教科書整章 PDF 拆解為各小節獨立課文。 | `整章 PDF` ➔ 各小節 `X-X 課名.md` ＋ 單節 `X-X.pdf` |
| **`lesson-core-summarizer`** | 提煉定義、對照表格、生活實例比喻與 4 句押韻好記口訣。 | `小節 md` ➔ `X-X 課名_摘要.md` |
| **`chalkboard-slides-planner`** | 依 NotebookLM 最優化規格，切分為 3 篇手繪黑板風大綱（每篇 4 頁、四要素、口播約 310 字）。 | `摘要 md` ➔ `X-X_01.md`, `X-X_02.md`, `X-X_03.md` |
| **`notebooklm-video-generator`** | 自動建立筆記本、注入大綱、套用黃金參數並啟動生成後交棒。 | `大綱 md` ➔ 自動觸發 NotebookLM 說明影片生成 |

## 🚀 完整 5 步標準作業流程（SOP）

```
【步驟 1：課本拆解】➔ 課本整章 PDF 拆為各小節 Markdown
       │
       ▼
【步驟 2：觀念提煉】➔ 產出 X-X_摘要.md（核心定義、比較表格、生活比喻、好記口訣）
       │
       ▼
【步驟 3：分鏡規劃】➔ 產出 3 段黑板風大綱（各鎖定 4 頁、口播約 310 字、單支 3.5 分鐘）
       │
       ▼
【步驟 4：影音渲染】➔ NotebookLM 套用黃金自訂參數，點擊「立即生成」後退場交棒
       │
       ▼
【步驟 5：片頭後製】➔ 下載 MP4 拖曳至「一鍵加入3秒無聲片頭.bat」，1 秒完成收心片頭！
```

## ⚙️ NotebookLM 渲染黃金標準參數

在 NotebookLM 點選「影片摘要（Video Overview）」時，套用以下黃金參數：

1. **格式**：選擇 **「說明影片」**（Explainer Video）。
2. **語言**：選擇 **「中文（繁體）」**。
3. **視覺風格**：選擇 **「自訂」** ➔ 貼入：
   ```text
   視覺風格：霧面深色黑板背景、手繪白與粉彩粉筆線條、教室手繪風字體（Chalkboard style with matte dark background and hand-drawn white/colored chalk lines）
   ```
4. **影片要以什麼內容為中心**：**維持預設（都不選）**。
5. **自訂主題**：貼入雙重約束（教學品質 ＋ 3.5分鐘嚴控）指令：
   ```text
   請依序，完整地講解來源文件的所有章節內容。請以生動清晰的講師講解、說明呈現，解說節奏俐落緊湊，結合生活實例，不遺漏任何重要概念，適合課堂教學的完整解說。
   但也請將本段教學影片長度嚴格控制在 3 分半鐘左右（約 3 分 30 秒至 4 分鐘之間），不要過度延伸閒聊或課外瑣事。
   ```
6. **點擊生成**：點擊 **「立即生成」**。

## ⚡ 一鍵安裝懶人包到您的 Antigravity

若要在其他電腦或全新環境中使用本套技能：

1. 下載本專案的 **`AGY-Notebook_20261120.zip`** 並解壓縮。
2. 雙擊執行目錄中的 **`install_skills.bat`**。
3. 4 大技能將自動安裝至本機全域技能庫（`~/.gemini/config/skills/`），即可在 Antigravity 對話框中直接以自然語言下達指令！
