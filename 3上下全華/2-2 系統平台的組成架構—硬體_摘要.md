# 2-2 系統平台的組成架構—硬體 重點摘要

---

## 📌 導言：什麼是電腦硬體？
* **口語講解**：同學請摸摸看手邊的螢幕、滑鼠與鍵盤，這些看得見、摸得著的實體設備就是「硬體（Hardware）」。硬體就像電腦的骨骼與肌肉，軟體則是靈魂，兩者必須完美搭配，電腦才能正常運作！
* **核心定義**：**硬體** 指系統平台中有形的實體設備，包括主機外觀及主機板內部所有的電子元件。

---

## 2-2-1 電腦系統架構（馮紐曼模式）

### 1. 內儲程式革命
* **歷史痛點**：早期的電腦（如 ENIAC）每做一種新計算，就必須手動重新拔插上千條線路，費時又容易接錯。
* **馮紐曼模式（Von Neumann Model）**：數學家馮紐曼提出「**內儲程式（Stored-program）**」概念，主張將「程式碼」與「資料」同時存放於記憶體中，再由 CPU 自動依序讀取指令執行，奠定了現代所有電腦與智慧型手機的架構基礎。

### 2. 電腦五大單元職責
現代電腦架構皆由以下「五大單元」分工合作組成：

| 單元名稱 | 英文簡稱 | 核心功能與白話說明 | 代表性設備／元件 |
| :--- | :---: | :--- | :--- |
| **輸入單元** | **IU** (Input Unit) | 接收外界訊息、資料與指令輸入電腦。 | 鍵盤、滑鼠、麥克風、掃描器、觸控面板 |
| **控制單元** | **CU** (Control Unit) | 指令解碼、指揮控制資料流向、協調各單元運作的中樞。 | CPU 內部的控制核心 |
| **算術邏輯單元** | **ALU** (Arithmetic/Logic Unit) | 負責算術運算（`+`、`-`、`×`、`÷`）與邏輯判斷（`AND`、`OR`、`NOT`）。 | CPU 內部的運算核心 |
| **記憶單元** | **MU** (Memory Unit) | 儲存資料與程式。分為主記憶體（執行暫存）與輔助記憶體（長期儲存）。 | RAM、ROM、硬碟、隨身碟 |
| **輸出單元** | **OU** (Output Unit) | 將電腦處理後的運算結果輸出給使用者。 | 螢幕顯示器、印表機、喇叭、耳機 |

> 💡 **關鍵整合**：**中央處理器 CPU ＝ 控制單元（CU） ＋ 算術邏輯單元（ALU）**。

### 3. 生活實例剖析：打成績運作五步驟
以「老師用 Excel 輸入全班成績並計算平均」為例，五大單元的接力運作如下：
```
步驟 1：滑鼠雙擊啟動 Excel ➔【輸入單元 IU】
   │
   ▼
步驟 2：作業系統將軟體載入記憶體 ➔【記憶單元 MU（主記憶體）】
   │
   ▼
步驟 3：鍵盤輸入各科分數 ➔【輸入單元 IU】
   │
   ▼
步驟 4：送交 CPU 進行算術計算 ➔【控制單元 CU 協調 ＋ 算術邏輯單元 ALU 計算】
   │
   ▼
步驟 5：螢幕顯示計算好的成績結果 ➔【輸出單元 OU】
```

* **口語記憶口訣**：**「輸進、記住、算邏控，處理完畢輸出用；CU是指揮官，ALU是算術兵！」**

## 2-2-2 CPU（微處理器）與機器週期

### 1. CPU 的內部架構
CPU（Central Processing Unit）是電腦的大腦與總指揮，微處理器將以下重要元件高度整合在單一積體電路中：
* **控制單元（CU）**：大腦司令官，指揮解碼與訊號發送。
* **算術邏輯單元（ALU）**：運算計算機，負責加減乘除與邏輯比較。
* **暫存器（Register）**：CPU 內部容量極小但**存取速度最快**的區域，暫存正在處理中的指令與資料位址。
* **快取記憶體（Cache Memory）**：位於 CPU 與主記憶體之間的高速緩衝區，存放最常被重複使用的指令或資料，**解決 CPU 超快與主記憶體較慢之間的速度落差**。
* **內部匯流排（Internal Bus）**：CPU 內部的專屬高速公路，傳輸資料、位址與控制訊號。

### 2. CPU 運作四部曲：機器週期（Machine Cycle）
CPU 每執行一個指令，必定經歷四個依序循環的階段：
```
【1. 擷取 (Fetch)】 ➔ 【2. 解碼 (Decode)】 ➔ 【3. 執行 (Execute)】 ➔ 【4. 儲存 (Store)】
```
1. **擷取（Fetch）**：根據位址，從主記憶體抓取下一個待執行的指令。
2. **解碼（Decode）**：由控制單元（CU）分析這個指令要做什麼。
3. **執行（Execute）**：指令交給算術邏輯單元（ALU）進行實際運算或判斷。
4. **儲存（Store）**：將運算好的最終成果寫回主記憶體中存放。

* **口語記憶口訣**：**「擷、解、執、存，CPU 循序運轉不留痕！」**

## 2-2-3 記憶體系統（主記憶體 vs. 輔助記憶體）

記憶體分為「**主記憶體**（執行程式的桌面）」與「**輔助記憶體**（長期藏書的書櫃）」兩大體系：

### 1. 主記憶體雙雄：RAM vs. ROM
* **依電性（Volatile，揮發性）**：電源關閉後，所存資料是否會隨之消失。

| 比較項目 | 隨機存取記憶體 RAM | 唯讀記憶體 ROM |
| :--- | :--- | :--- |
| **全名** | Random Access Memory | Read-Only Memory |
| **讀寫特性** | **可隨機讀取、亦可寫入** | **平時只能讀取，不可任意更改** |
| **依電性** | **依電性（揮發性）**：關機斷電資料立即消失！ | **非依電性（非揮發性）**：斷電資料永久保存！ |
| **核心用途** | 暫存**正在執行**的作業系統、軟體程式與資料。 | 存放開機必備的核心程式（如早期主機板 BIOS）。 |
| **現代演進** | DDR4、DDR5 模組（俗稱的電腦記憶體大小）。 | 現多採用可更新的「快閃唯讀記憶體（Flash ROM）」。 |

> 💡 **生活比喻**：**RAM 是你的「書桌桌面」**，桌子愈大（16GB、32GB），可以同時翻開愈多本作業；但下課桌面會清空。**ROM 就像書桌抽屜上印好的「原廠出廠烙印」**，永遠抹不掉。

### 2. 輔助記憶體（儲存設備 Storage Device）
* **核心特色**：**容量超大、成本低廉、非依電性（斷電資料不消失）**，但讀寫速度比主記憶體慢。
* **常見儲存設備對比**：
  * **硬碟（HDD）**：內部覆蓋磁性碟片，以磁性存取，出廠第一次使用必須先執行「**格式化（Format）**」。
  * **固態硬碟（SSD）/ 隨身碟**：採用**快閃記憶體（Flash Memory）**製作，防震、耐攜帶、傳輸速度快。
  * **光碟（CD / DVD / 藍光 BD）**：利用**雷射光**進行資料讀取與高熱燒錄。

* **口語記憶口訣**：**「RAM 斷電忘光光、ROM 唯讀開機幫、輔助記憶體慢慢裝（斷電依然在）！」**

## 2-2-4 輸入設備與 2-2-5 輸出設備

### 1. 輸入與輸出設備總覽
* **輸入設備（Input）**：把使用者的意圖化為電子訊號送進電腦。
  * **鍵盤**：最主要文字輸入設備（PS/2、USB、無線藍牙）。
  * **滑鼠**：主流為光學滑鼠與藍光滑鼠。
  * **掃描器**：將紙本照片轉為數位影像檔（常見為平台式掃描器）。
  * **麥克風**：聲音接收裝置，連接至音效卡上的「**粉紅色插孔**」。
* **輸出設備（Output）**：將電腦算好的訊號轉為人類感官看得見、聽得到的成品。
  * **顯示器（螢幕）**：最基本視覺輸出設備。
  * **印表機**：紙本文件列印。
  * **喇叭／耳機**：聲音輸出裝置，連接至音效卡上的「**綠色插孔（音源輸出）**」。

### 2. 考試地雷與易混淆考點
* ⚠️ **地雷警示：觸控式螢幕（Touch Screen）**：
  * 單純螢幕是【輸出單元】。
  * 但若是**「觸控式螢幕」**（如手機螢幕、ATM 觸控板），用手點擊是輸入、畫面顯示是輸出，因此**兼具「輸入」與「輸出」雙重功能**！
* ⚠️ **音效卡插孔顏色配對**：
  * **粉紅色孔** ➔ 麥克風（輸入 IU）。
  * **綠色孔** ➔ 喇叭、耳機（輸出 OU）。

* **口語記憶口訣**：**「粉紅麥克風收話、翠綠喇叭耳機聽音樂、觸控螢幕能進又能出！」**

## 2-2-6 實作演練：查看電腦硬體設備

### Windows 11「裝置管理員（Device Manager）」
* **功能**：檢視並管理所有連接至電腦的各項實體硬體狀態（顯示卡、CPU、鍵盤、連接埠等），驅動程式異常時會在此標示黃色驚嘆號。
* **兩種最快開啟方式**：
  1. **快捷選單法**：在工作列的「開始」按鈕上按**滑鼠右鍵**（快捷鍵 `Win + X`）➔ 點選「裝置管理員」。
  2. **搜尋方塊法**：點擊工作列搜尋框 ➔ 直接輸入「裝置管理員」即可開啟。
