# 2-2 系統平台的組成架構—硬體

<!-- PDF 頁碼: 8 -->

硬體是指系統平台中有形的實體設備，舉凡電腦的外觀及主機內可見的元

件，例如顯示器、滑鼠、鍵盤、主機、印表機等，都屬於硬體。本節將以常見

的桌上型電腦來說明有關電腦硬體的組成架構。

2-2-1 電腦系統架構

早期的電腦是透過許多電纜線的排列與串接，來

設定要執行的程式與工作任務（圖2-7）。這種透過

安裝線路來設定運算程序的方式十分不便，因此數

學家馮紐曼（John von Neumann）提出「內儲程式」

的概念，主張以記憶體來儲存欲執行的程式與資料，

再交由CPU 依序執行指令及存取資料，從此改變了

電腦的操作方式，也確立現代電腦的架構。

現今的電腦，都是依循著以內儲程式為概念的馮紐曼模式（Von Neumann

Model）架構所組成，主要分為控制單元、算術與邏輯單元、記憶單元、輸入單

元以及輸出單元等五大單元，所需的資料與指令由輸入單元載入至記憶單元，

再由控制單元協調各單元的運作、執行與輸出，彼此之間的關係如圖2-8 所示。

這五大單元有著密不可分的關係，分別說明如下。

記憶單元

記憶單元（Memory Unit, MU）主要是用來儲存資料或程式，記憶單元又

可分為主記憶體（main memory）和輔助記憶體（auxiliary memory）二種。

主記憶體是程式執行時，暫時存放程式碼和資料的地方，例如主機板上的

記憶體模組；而輔助記憶體主要是作為檔案、程式或資料長期儲存及備份之用，

例如硬碟、光碟及隨身碟。

控制單元

控制單元（Control Unit, CU）主要負責指令的解碼、控制資料的流向、

指揮各單元之間的運作，是電腦的運作中樞。控制單元會發出控制訊號，協調

各單元合力完成指定的工作。

算術邏輯單元

算術邏輯單元（Arithmetic/Logic Unit, ALU）主要是負責算術（例如＋、

－、×、÷ 的計算）和邏輯運算（例如AND、OR、NOT 的判斷）的工作，

它必須依據控制單元的指示，對所接收到的資料做前述運算的工作。它和「控

制單元」合稱為中央處理器（Central Processing Unit, CPU）（圖2-9）。

輸入單元

輸入單元（Input Unit, IU）是負責接收外部資料與指令，以供電腦進行處

理的管道。常見的輸入裝置有：鍵盤、滑鼠、數位板、條碼閱讀機、掃描器、

觸控式顯示器、麥克風等，這些裝置都可以將外界的訊息輸入到電腦系統中。

輸出單元

輸出單元（Output Unit, OU）主要是負責把電腦處理後的結果輸出給電腦

的使用者。常見的輸出裝置有：印表機、喇叭、顯示器、繪圖機等。

2-2-2 CPU

CPU 是電腦中最重要的一部分，它就像人類的頭腦一樣，是電腦處理資料

的總指揮，它主宰著整部電腦的運作與執行，也是實際用來執行程式解碼、資

料處理、邏輯判斷及運算的部門。

CPU 又稱為微處理器（microprocessor），是將控制單元、算術邏輯單元、

暫存器（register）、快取記憶體（cache memory）及內部匯流排（internal

bus）等元件整合製作在一個積體電路中，如圖2-10 所示。

z 暫存器：是CPU 內部的儲存區域，用來暫時存放處理中的指令、資料、位

z 快取記憶體：CPU 執行工作時，都必須到主記憶體去提取指令、資料，但

或資料。


z 內部匯流排：在CPU 內部，負責連接不同單元與傳輸資料、訊號的通道。

主記憶體

一般所稱的「記憶體」大多指的是主記憶體，主記憶體依存取特性可分為

隨機存取記憶體（Random Access Memory, RAM）與唯讀記憶體（Read-Only

Memory, ROM）。

隨機存取記憶體RAM

RAM（圖2-13）是可以隨機存取的記憶體。所謂的隨機，是指可以直接存取

任何一個位址的資料。RAM 是依電性（volatile）記憶體，一旦斷了電源，資料也

跟著消失，因此RAM 是用來存放處理中的程式或資料。


▲圖2-13　我們所說的電腦記憶體，指的就是RAM

唯讀記憶體 ROM

ROM 是非依電性（non-volatile）的記憶體，即使電源消失，裡面的內容仍

然存在。因此，ROM 主要用於存放重要及不希望被任意更改的系統程式及資

料，例如早期電腦主機板上的BIOS（Basic Input

Output System，基本輸入輸出系統），是由主機

板製造廠直接將開機程式燒錄在ROM 晶片裡（圖

2-14），隨著硬體技術的進步，現在的BIOS 多

儲存於可讀可寫的快閃記憶體（Flash ROM）

晶片上。

輔助記憶體

通常輔助記憶體的容量比主記憶體大，成本也比較低，而且電源關閉後，

其內的資料也不會消失，因此是屬於非揮發性的記憶體，但它的存取速度較

慢。常見的輔助記憶體有：硬碟、光碟片、隨身碟等，這些輔助記憶體常稱之

為儲存設備（storage device）。

隨 身 碟

隨身碟（圖2-17）是使用快閃記憶體製作而成，透過USB 介面的

傳輸，讓隨身碟成為攜帶方便的儲存設備。相較於其他可攜式儲存

裝置，隨身碟具有不佔空間、傳輸速度快、可重複讀寫、儲存

容量也較大等優點。

硬 碟

硬碟（圖2-15）的內部主要是由許多同圓心軸

的金屬碟片堆疊組合而成，碟片的表面覆蓋一層磁性

媒介，以磁性型態儲存資料，故稱為硬式磁碟機（Hard

Disk Drive, HDD）。每個硬碟第一次使用時都必須經過格

式化（format）之後才可以使用。

光碟（Compact Disc）利用雷射光來讀取或燒錄資料，薄

薄的一片圓盤就能儲存大量檔案資料。常見的光碟片有CD、

DVD（圖2-16）、藍光光碟等。
