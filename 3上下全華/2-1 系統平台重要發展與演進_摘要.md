# 2-1 系統平台重要發展與演進 重點摘要

---

## 📌 導言：什麼是系統平台？
* **口語講解**：同學想像一下，如果你有一輛最新款的超跑（應用軟體），但沒有馬路、沒有輪胎（作業系統與硬體），車子動得了嗎？「系統平台」就是讓應用程式能夠順暢執行的完整環境！
* **核心定義**：**系統平台（Computing Platform）** 是使用者運用數位科技的重要媒介，主要由「**硬體（Hardware）**」與「**軟體（Software）**」兩大部分組成，並透過「**網路通訊技術**」串聯協調，三者緊密搭配、缺一不可。

---

## 2-1-1 計算工具的演進

從人類最早的算盤到現代電腦，計算工具經歷了漫長的智慧淬鍊：

| 年代／時期 | 發明家／代表人物 | 重要發明／核心貢獻 | 歷史地位與影響 |
| :--- | :--- | :--- | :--- |
| **遠古時期** | 中國老祖先 | **算盤** | 人類最早的計算工具（五千年前）。 |
| **1642 年** | 巴斯卡（Blaise Pascal） | **機械式加法器（Pascaline）** | 利用齒輪帶動自動進位，開創「機械計算時期」。 |
| **1822 年** | 巴貝奇（Charles Babbage） | **差分機（Difference Engine）** | 以蒸氣引擎為動力，可解多項式與四則運算，被譽為「電腦之父」。 |
| **1889 年** | 何樂禮（Herman Hollerith） | **打孔卡片機** | 以打孔卡片儲存資料並排序，協助完成 1890 年全美人口普查。 |
| **1942 年** | 阿塔納索夫 & 貝利 | **ABC 電腦** | 第一部可用「電子訊號將資料編碼」的電子式數位電腦。 |
| **1945 年** | 馮紐曼（John von Neumann） | **內儲程式（Stored-program）** | 主張以記憶體同時儲存程式與資料，確立現代電腦運算架構。 |
| **1946 年** | 牟其利 & 艾克特 | **ENIAC** | 世界上第一部「通用型」電子計算機，正式邁入第一代電腦。 |

* **口語記憶口訣**：**「巴斯卡齒輪加、巴貝奇差分機、何樂禮打孔卡、馮紐曼內儲立典範」**。

## 2-1-2 電子元件的發展（五代電腦世代）

電腦演進是以**硬體基礎元件的重大變革**來劃分世代：

| 世代 | 年代起點 | 代表電子元件 | 體積與運算特色 | 代表機種／關鍵特徵 |
| :---: | :---: | :--- | :--- | :--- |
| **第一代** | 1946 年 | **真空管（Vacuum Tube）** | 體積巨大（如兩間教室）、耗電、易發熱、價格極昂貴 | ENIAC（首部通用電腦） |
| **第二代** | 1959 年 | **電晶體（Transistor）** | 體積大幅縮小、速度快、耗電低、運作穩定 | 迅速取代真空管，電腦邁向商業實用 |
| **第三代** | 1964 年 | **積體電路（IC）** | 將電阻、電晶體等濃縮至矽晶片，更省電、更便宜 | 製造朝向「小、快、廉」發展 |
| **第四代** | 1971 年 | **超大型積體電路（VLSI）** | 超高密度 IC，微處理器誕生，個人電腦（PC）普及 | 輕薄短小、運算速度飛躍提升 |
| **第五代** | 1990 年~ | **人工智慧（AI）** | 跳脫傳統硬體元件劃分，改以 AI 軟體提升自主學習與推理能力 | 語音交談、機器人、自適應智慧系統 |

* **口語記憶口訣**：**「真（真空管）➔ 晶（電晶體）➔ 積（積體電路）➔ 超（超大型 IC）➔ 智（人工智慧）」**。

## 2-1-3 網路發展歷程（關鍵年代與演進脈絡）

電腦網路打破了地理藩籬，從軍事通訊發展為全球數位生活基礎：

| 年代 | 里程碑事件 | 核心意義與現代生活影響 |
| :---: | :--- | :--- |
| **1967** | **ARPANET 誕生** | 美國國防高等研究計畫署設計，網際網路的前身。 |
| **1971** | **電子郵件（Email）** | 雷．湯林森發明，成為網路最重要的溝通工具之一。 |
| **1974** | **TCP/IP 通訊協定** | 文頓．瑟夫與羅伯特．卡恩提出，奠定全球網路通訊標準。 |
| **1989** | **全球資訊網（WWW）** | 伯納斯-李提出，超文字超連結讓大眾輕鬆瀏覽網頁。 |
| **1996** | **Google 搜尋引擎** | 讓使用者從全球海量資料中秒級檢索精準資訊。 |
| **1997** | **IEEE 802.11 標準** | 統一無線網路規範，Wi-Fi 無線生活正式啟航。 |
| **2004~2006** | **社群與雲端運算** | Facebook、Twitter 掀起社群狂潮；Google 正式提出雲端運算（Cloud Computing）。 |
| **2007** | **第一代 iPhone** | 智慧型手機奠定行動網路時代，行動上網成為全民趨勢。 |
| **2008~2011** | **瀏覽器與即時通訊** | Google Chrome 問世、LINE 跨平台即時通訊成為日常。 |
| **2024~** | **網路普及與生成式 AI** | 全球上網人口破 66 億；ChatGPT 引爆生成式 AI 與數位轉型熱潮。 |

* **口語記憶口訣**：**「阿帕網起步、TCP/IP 定規矩、WWW 連全球、智慧手機與 AI 領風騷」**。
