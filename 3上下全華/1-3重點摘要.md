# 1-3 資料處理 核心重點摘要（口語教學版）

---

## 📌 導言：為什麼需要電腦做資料處理？
* **口語講解**：同學請想一下，以前沒有電腦時大家怎麼算帳？用算盤或紙筆，只要算錯一個數字就全盤皆輸。
* **核心觀念**：將資料轉換為可用資訊的過程就是「資料處理」。電腦搭配試算表處理具備「速度快、不易出錯」兩大優勢。

---

## 1-3-1 資料與資訊

### 1. 資料 vs. 資訊
* **資料（Data）**：未經處理的客觀事實，本身沒有特定意義。  
  *(例：全班每位同學的身高體重、考試原始分數)*
* **資訊（Information）**：經過特定目的處理、歸納與解釋後，產生具有參考價值的訊息。  
  *(例：全班平均身高、成績排名與及格率)*
* **口語記憶口訣**：**「資料是原料，資訊是成品」**；同一筆資料對不同人意義不同（例如圖書銷量對讀者是數字，對出版社是市場預測指標）。

### 2. 資料處理三要素
```
【輸入 (Input)】 ➔ 【處理 (Process)】 ➔ 【輸出 (Output)】
```
* **輸入**：收集並鍵入原始資料。
* **處理**：分類、排序、計算、分析。
* **輸出**：產生報表、圖表或結論資訊。

### 3. 常見四種資料處理型態
| 型態 | 核心特色 | 口語生活實例 |
| :--- | :--- | :--- |
| **批次處理** | 累積一段時間或量，時間到了「一次性集中處理」 | 水電費計算、每月發薪水、國中教育會考閱卷 |
| **即時處理** | 收到指令後，必須在限定時間內「立刻回應」 | 銀行 ATM 提款、高鐵訂票、飛航管制、保全監控 |
| **交談式處理** | 使用者與電腦「一問一答」互動溝通 | 軟體安裝精靈、填寫會員註冊表單、ATM 螢幕按鍵操作 |
| **分散式處理** | 多部工作站「分工合作執行」，最後再匯整成果 | 跨校／跨館圖書借閱系統、雲端分散式伺服器 |

## 1-3-2 資料前處理

### 1. 核心觀念：GIGO 原則
* **英文全名**：**Garbage In, Garbage Out**（垃圾進，垃圾出）。
* **口語講解**：如果輸入的原始資料是錯的或亂的，運算能力再強的電腦也只能算出錯誤的垃圾結果！
* **真實世界的資料問題**：遺漏缺值、雜訊極端值、格式不一致。

### 2. 資料前處理三階段
```
【1. 資料清理】 ➔ 【2. 資料整合】 ➔ 【3. 資料轉換】
```

#### ① 第一階段：資料清理（抓錯與補洞）
* **修補遺漏**：缺考或漏填欄位，可選擇剔除或用「平均數 / 眾數」填補。
* **去除雜訊與極端值**：修正不合理數值（如年齡出現負數、國中生身高 300 公分）。
* **修正不一致**：統一編碼格式（例如性別欄不能同時混雜「男/女」與「1/2」）。

#### ② 第二階段：資料整合（化異為同、合併資料）
* **目的**：將不同來源的資料合併，解決重複與標準對齊問題。
* **避坑重點**：
  * **名稱重複**：例如來源 A 寫「臺灣」、來源 B 寫「中華民國」，合併時容易誤當成兩筆資料。
  * **單位不同**：例如攝氏（°C）與華氏（°F）沒對齊就合併，會造成嚴重誤判。

#### ③ 第三階段：資料轉換（數值統一標準）
* **目的**：轉換單位或計算合成指標，避免後續演算法出錯。
* **實例**：
  * 將體重與身高轉換計算為 **BMI 指標**。
  * 跨國報表將不同幣別（新台幣、美金）依匯率統一為同一幣值。

## 💡 實作延伸：善用 AI 工具整理資料（以 ChatGPT 為例）
* **口語提點**：AI 是極佳的資料清理小幫手，但關鍵在於「提示詞（Prompt）要具體明確」。
* **下指令三大要素**：
  1. 指定**清楚的欄位名稱**（例如：訂單編號、訂購人、總金額）。
  2. 明確指定**統一的格式**（例如：日期一律以「X月X日」呈現）。
  3. 明確給出**計算規則**（例如：總金額＝單價 × 數量）。
* **後續應用**：AI 整理出結構化表格後，可一鍵複製至 Excel 或 Google 試算表進行後續運算與圖表呈現。
