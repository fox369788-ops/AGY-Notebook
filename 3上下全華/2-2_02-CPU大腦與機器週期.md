### Slide 2｜微處理器內部五大元件
* **【黑板手繪構圖】**：
  - 黑板中央畫一顆方形 CPU 晶片剖面圖，內部清楚劃分出五大區域：
    - 上方：【控制單元 CU】（畫指揮棒）。
    - 下方：【算術邏輯單元 ALU】（畫運算符號）。
    - 右上方：【暫存器 Register】（標註「速度最快」）。
    - 右下方：【快取記憶體 Cache】（標註「高速緩衝」）。
    - 貫穿中央：【內部匯流排 Internal Bus】（畫多線道高速公路）。
* **【核心知識點】**：
  - **暫存器（Register）**：CPU 內部容量極小、但**存取速度世界第一快**的暫存區，專門放正在處理的指令與位址。
  - **快取記憶體（Cache Memory）**：位在 CPU 與主記憶體之間的高速緩衝區，存放常被重複取用的資料，**解決 CPU 超快與記憶體較慢之間的速度瓶頸**。
  - **內部匯流排（Internal Bus）**：CPU 內部專屬的高速公路，負責在各單元間傳遞資料與訊號。
* **【口播引導】**：
  - 「CPU 內部有五大核心骨幹：CU 指揮、ALU 運算、暫存器以光速暫存目前數據；而快取記憶體就像隨身急救包，把常用的資料抓在身邊，不用每次都跑遠路去主記憶體搬，大幅解決塞車問題！」

### Slide 3｜CPU 運作四部曲：機器週期
* **【黑板手繪構圖】**：
  - 中央以湖藍粉筆畫出一個圓形順時針旋轉的四段循環箭頭：
    - ①擷取 Fetch ➔ ②解碼 Decode ➔ ③執行 Execute ➔ ④儲存 Store。
  - 左側畫主記憶體，右側畫 ALU 運算器，用箭頭連動各階段。
* **【核心知識點】**：
  - **機器週期（Machine Cycle）**：CPU 處理一道指令必經的四個標準階段。
  - **階段 1【擷取 Fetch】**：依位址從主記憶體把下一個指令抓進 CPU。
  - **階段 2【解碼 Decode】**：由控制單元（CU）分析指令意圖，發出控制訊號。
  - **階段 3【執行 Execute】**：指令交給算術邏輯單元（ALU）進行實際運算。
  - **階段 4【儲存 Store】**：將運算出來的最後結果寫回主記憶體。
* **【口播引導】**：
  - 「CPU 處理每一件工作都嚴格遵守四步驟：第一『擷取』，從記憶體抓指令；第二『解碼』，CU 翻譯要幹嘛；第三『執行』，ALU 動手運算；第四『儲存』，算完寫回記憶體。循環往復，就是所謂的機器週期！」
