# NotebookLM 說明影片自動化生成與片頭後製技能 (notebooklm-video-generator)

本技能用於將產出的「手繪黑板風投影片大綱」，透過瀏覽器代理在 **Google NotebookLM** 實現半自動化的影片生成啟動，並搭配本機極速批次工具完成「3 秒無聲收心片頭」的成片後製。

---

## 📌 人機分工與安全退場機制

| 環節 | 執行角色 | 具體動作 |
| :--- | :---: | :--- |
| **1. 帳號登入** | **使用者** | 在內建瀏覽器面板中完成一次 Google 帳號與 2FA 登入，並維持工作階段連線。 |
| **2. 建立筆記本** | **AI 代理** | 前往 `https://notebook.google.com/`，點擊新增筆記本。 |
| **3. 載入大綱來源** | **AI 代理** | 開啟「貼上複製的文字（Copied text）」，貼入大綱完整 Markdown 文字，點擊「插入」完成載入（避開瀏覽器本地檔案注入限制）。 |
| **4. 套用黃金參數** | **AI 代理** | 點擊右側工作室「影片摘要」，自動填入格式、黑板風格與 3.5 分鐘自訂主題。 |
| **5. 點擊立即生成** | **AI 代理** | 按下「立即生成」按鈕，確認旋轉進度條啟動（「正在研擬流程...」）。 |
| **6. 標準退場交棒** | **AI 代理** | **一旦確認生成啟動，AI 代理立即結束任務並退場交棒**，由使用者在瀏覽器背景等待渲染（約 2~4 分鐘）並自行下載 MP4。 |
| **7. 片頭 3 秒後製** | **使用者** | 下載後將 MP4 檔案拖曳至同目錄下的 `一鍵加入3秒無聲片頭.bat`，1 秒生成正式成片！ |

---

## ⚙️ NotebookLM 渲染黃金標準設定值

在設定「影片摘要（Video Overview）」時，代理必須嚴格依序套用以下參數：

1. **格式**：選擇 **「說明影片」**（Explainer Video）。
2. **語言**：選擇 **「中文（繁體）」**。
3. **視覺風格**：選擇 **「自訂」** ➔ 於自訂視覺風格框貼入：
   ```text
   視覺風格：霧面深色黑板背景、手繪白與粉彩粉筆線條、教室手繪風字體（Chalkboard style with matte dark background and hand-drawn white/colored chalk lines）
   ```
4. **影片要以什麼內容為中心**：**維持預設（都不選）**，確保 AI 覆蓋全篇大綱。
5. **自訂主題**：貼入雙重約束（教學品質 ＋ 3.5分鐘嚴控）指令：
   ```text
   請依序，完整地講解來源文件的所有章節內容。請以生動清晰的講師講解、說明呈現，解說節奏俐落緊湊，結合生活實例，不遺漏任何重要概念，適合課堂教學的完整解說。
   但也請將本段教學影片長度嚴格控制在 3 分半鐘左右（約 3 分 30 秒至 4 分鐘之間），不要過度延伸閒聊或課外瑣事。
   ```
6. **點擊生成**：點擊 **「立即生成」**。

---

## ⚡ 步驟七：片頭 3 秒無聲後製（一鍵拖曳工具）

NotebookLM 原生語音必定從 `00:00` 秒開講，無法直接產出安靜收心片頭。透過放置於同目錄的批次檔：
* **工具路徑**：`{課本PDF同目錄}\一鍵加入3秒無聲片頭.bat`
* **使用方式**：直接將下載的 MP4 影片**拖曳放到該 `.bat` 圖示上**，1 秒鐘內即可無損產出 `_3秒片頭.mp4` 成品！
