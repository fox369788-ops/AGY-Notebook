# 課本整章 PDF 依節拆解技能 (textbook-pdf-splitter)

本技能用於將出版商或教師提供的「整章教科書 PDF」，依據目錄結構與內文小節標題，精準拆分為各小節獨立的 Markdown 課文與單元 PDF 檔，作為後續教材整理與微影片製作的標準數位來源。

---

## 📌 執行規範與原則

### 1. 儲存原則（單一目錄原則）
* **集中管理**：所有拆解產出之小節 `.md` 檔案與小節 `.pdf` 檔案，**統一儲存於與原始整章 PDF 相同的資料夾目錄中**（例如 `D:\AGY-Notebook\3上下全華\`）。
* **不分散**：不主動建立額外多層子資料夾或分散備份，確保全章素材一目了然。

### 2. 命名規範
* **Markdown 檔名**：`{小節編號} {小節名稱}.md`
  * 範例：`2-1 系統平台重要發展與演進.md`、`2-2 系統平台的組成架構—硬體.md`
* **獨立小節 PDF 檔名**：`{小節編號} {小節名稱}.pdf`
  * 範例：`2-1 系統平台重要發展與演進.pdf`、`2-2 系統平台的組成架構—硬體.pdf`

---

## 🛠️ 拆解作業步驟

1. **PDF 結構與目錄解析**：
   * 讀取前 2 頁的章節學習目標與單元目錄（TOC），確認該章包含的所有小節名稱與次序。
   * 搜尋內文各小節（如 `2-1`、`2-2`、`2-3`、`2-4`）的起始頁碼與結束頁碼。
2. **第一小節特殊處理**：
   * 章節封面頁（Chapter Cover）、學習目標與全章目錄頁，統一包含於「第一小節（如 2-1）」的檔案頭部。
3. **文本提取與乾淨化清洗**：
   * 使用 PyMuPDF (`fitz`) 提取每頁文本。
   * **保留頁碼註記**：每頁開頭插入 `<!-- PDF 頁碼: X -->` 標籤，方便日後溯源。
   * **去除頁尾與版面雜訊**：
     * 去除書籍底部頁碼（如 `38`、`40`、`42`）。
     * 去除直式書籍書眉／側邊章節裝飾文字（如 `2\n系\n統\n平\n台`）。
     * 清理頁尾裝飾性出版資訊或空白多餘空行。
   * 保留圖表編號標記（如 `▲圖2-8 五大單元關係圖`）與重點方框標註。
4. **同步生成小節 PDF 檔**：
   * 依據確認的頁碼範圍，以 PyMuPDF 切出單節獨立的 `.pdf` 檔案，存於同目錄。
