# 課文核心重點摘要提煉技能 (lesson-core-summarizer)

本技能用於將教科書小節 Markdown 課文，轉化為條列清晰、結構嚴謹且「適合教師課堂口語講解」的核心重點摘要。去蕪存菁，不遺漏任何考試與課綱必備概念。

---

## 📌 執行規範與原則

### 1. 儲存位置與命名
* **儲存路徑**：直接儲存於**來源小節 Markdown 檔案所在的同一個資料夾**（單一目錄原則）。
* **檔案命名**：`{來源檔名}_摘要.md`
  * 範例：`2-2 系統平台的組成架構—硬體_摘要.md`

### 2. 重點摘要四大必備要素（交付標準）
每一份摘要必須依序包含以下四大部分：

1. **生活痛點與導言引入**：
   * 用 1~2 句生活痛點問句開場（例如：「報告寫到一半電腦突然斷電怎麼辦？」），白話解釋為何需要學習本節觀念。
2. **核心名詞定義與結構圖**：
   * 每個核心專業名詞附帶一句「白話說明」與其「英文縮寫／全名」。
   * 流程性概念以 ASCII 流向圖呈現（例如：`輸入 ➔ 處理 ➔ 輸出` 或 `擷取 ➔ 解碼 ➔ 執行 ➔ 儲存`）。
3. **高密度比較表格與生活比喻**：
   * 針對易混淆名詞建立結構化對比表格（例如：`RAM vs. ROM`、`五大單元分工表`、`五代電子元件對比表`）。
   * 引入生動的生活實體比喻（例如：RAM 是書桌桌面、ROM 是抽屜鋼印、硬碟是書櫃）。
4. **考試地雷避坑警示與好記口訣**：
   * 標註大考常考的易錯觀念（例如：觸控螢幕兼具輸入與輸出、音效卡粉紅孔接麥克風／綠孔接耳機）。
   * 每一個主要觀念區塊結尾，必須提煉出 **4 句押韻、朗朗上口的好記口訣**。
